# V2.1 六项首版功能本地验收

2026-11-18。工作区运行时为 Node 22.23.1、npm 10.9.8、项目自带 Go。以下命令从 WSL 项目根目录运行。浏览器验收使用独立的本地 Next.js 端口和显式接口测试数据。链码使用内存账本。站点功能使用已有的 `postgres:16-alpine` 镜像和一次性 PostgreSQL 数据库，资产存在性查询在该测试中使用固定样例。

## 复跑命令

```bash
source infrastructure/scripts/env.sh
(cd chaincode && go test -count=1 ./... && go vet ./...)
npm test --workspace @trustguard/api
node services/api/scripts/verify-scan-observations.mjs
npm run lint --workspace @trustguard/web
bash tests/verify-v21-web.sh
```

浏览器脚本会构建前端，使用 Chromium 在本机 3187 端口运行六项检查，结束后关闭测试服务。PostgreSQL 脚本仅向独立的临时数据库写入。本轮未部署链码、重启业务服务或向 Fabric 提交交易。已有网络要操作新增链码命令，需要另行授权升级链码，并启用匹配的 API、密钥服务、前端与数据库迁移。

本轮实测结果：Chromium 6/6、API 26/26、独立配置下的基础设施测试 4/4 通过。Go 两个包的测试及 go vet、前端类型检查、ESLint、生产构建、PostgreSQL 并发与时间窗口专项均通过。配置测试需要它自行设置 Fabric 目录，可用 `env -u FABRIC_CFG_PATH .venv/bin/python -m pytest -q tests/test_business_config.py` 单独复跑。

## 逐项判定

| 功能 | 操作 | 通过条件 |
| --- | --- | --- |
| 扫码查档 | 在电池数字身份页打开已建档的电池，读取卡片二维码，或用“识别二维码图片”选择该码截图。拒绝相机权限后再用图片查询。 | 相机和图片都能识别到正确的 24 位码，刷新仍打开该档案。无效图像、相机不可用均有反馈。自动化相机画面来自实际渲染的二维码。手机实测需要设备能访问二维码中同一站点，网页调用相机需要 HTTPS 或 localhost。 |
| 字段证据 | 点生产日期、设计寿命、首用或报废日期，再展开健康度证据。 | 显示该字段对应的写入交易、时间或来源摘要。后续资产更新不会被标成生产日期来源。无首用或报废记录时显示缺失。获授权且有健康快照时可见 SOH 的测量时间和摘要。 |
| 单电芯正向追溯 | 在谱系页切换正向模式，分别选同一批次中分装到不同 PACK 的两颗电芯，再选未装配电芯。 | 每次只显示所选电芯和它当前所属的模组、PACK。未装配电芯没有下游，刷新保留所选电芯。批次影响范围仍使用批次查询。 |
| 整批质检与独立复检 | 检测中心选批次，由 lab-inspector 签发不合格报告。由 lab-auditor 提出复检，再切换 lab-inspector、重新选同一对象、签发新版本。 | 不合格批次拦截所含电芯所在 PACK 的放行。直接改签合格、自提自签和旧版本请求均被拒绝。两个报告版本和复检提议、签发交易可核对。复检后仍须通过单资产质检和原有放行审批。 |
| MES 批量导入 | 下载数字身份页的四份样例。依次用 cell-manufacturer 导入生产文件、pack-manufacturer 导入模组与包建档、cell-manufacturer 导入供货授权、pack-assembler 导入装配。样例使用预置模拟厂商 SMA、DMA。 | 生成一条电芯→模组→PACK 路径。相同身份重传原文件得到原凭证。任一行失败时整份文件不生效。检查签名时修改记录顺序或更换签名身份均会被拒绝。仅支持显式仿真 JSON，每份 1–100 行。 |
| 异地重复码预警 | 勾选“扫码时登记本站”，先在电芯厂扫描，10 分钟内切换检测站身份扫描同一码。也可在确认实物后点击“登记本站扫码”。 | 跨站记录显示前后站点并触发复核提示。同站连续扫描、超出窗口不产生新冲突，并发重试同一请求只写一条。普通查看、刷新档案不会生成扫码记录。审计角色可查看各站，业务角色仅查本站记录。 |

## 验证边界

站点取自组织证书映射的四个演示站点，时间取自数据库。10 分钟是本地仿真预警阈值，预警用于人工复核。未验证真实 GPS、物理标签或手机摄像头。MES 文件由当前演示身份签名，尚无真实工厂接入。整批报告独立于单电芯报告，合格批次不会覆盖不合格电芯。寿命预测继续按既有规则显示缺少有效模型。
